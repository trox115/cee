# Contributing to CEE

CEE v0.1 is experimental. Small, evidence-based proposals are preferred over broad rewrites.

1. Open an issue describing the communication failure and a before/after example.
2. Reference the affected rule ID (for example, `REV-003`). Do not silently reuse or renumber rule IDs.
3. Explain why the change improves correctness, evidence, clarity, or reading effort.
4. Add or update an anonymized example; include a counterexample where useful.
5. Submit a focused pull request with a summary and the validation you performed.

Use English for normative specification text. Avoid breaking changes to rule meanings without discussing versioning.

**Privacy:** Do not include proprietary diffs, credentials, internal URLs, personal data, or private logs. You must have rights to contribute your material.
