# Proposed validation plan for CEE v0.3

This is a plan, not an executed semantic evaluation or authorization for new model calls. Version: `0.3.0-rc.1`. Independent human incident validation remains incomplete. AI-assisted adjudication is not a substitute for that independent evidence.

## Deterministic release-candidate checks

- Verify the version, unique rule IDs and normative levels against the prior specification.
- Confirm that REV-015 indexes the existing severity duty and that conditional SHOULD clauses remain conditional.
- Check specification, profile, skill and example consistency; verify all local documentation links.
- Verify that no private evidence, proprietary identifiers or credentials enter public files.
- Preserve historical artifact checksums and original bindings. Keep infrastructure and old scoring implementations unchanged.

These checks establish mechanical consistency and preservation, not semantic correctness, comprehension gains or evaluator reliability.

## Separately authorized semantic validation

Before execution, approve a plan defining the exact version identities, sample, reference/adjudication procedure, blinding, evaluator configuration, costs and stopping conditions. Use the [benchmark protocol](../benchmarks/protocol.md), keeping findings, replies and non-finding statements separate. A new condition must not silently relabel or rescore historical results.

Include relevant preservation, inherited-error, transformation, applicability, overlap and conditional-recommendation examples. Keep clean communications distinct from code that happens to contain a real defect. Report technical validity, language compliance, evidence limits, publication decision, severity and fix outcomes separately.

Use exact response spans for incident assessment, independently of rule attribution. Record uncertain and unmatched complaints, missing rules and reference challenges. Do not count a familiar rule ID as incident detection or fabricate precision while distinct complaints remain unresolved. Report raw counts and sample sizes alongside rates.

If independent human validation is later commissioned, keep it separate from AI-assisted records and disclose any prior exposure. Freeze annotations before disclosing variant or model identity. Measure reading time or comprehension directly before claiming a reading benefit.

## Proposed acceptance boundary

Do not accept compression at the cost of technical validity, evidence or critical conditions. Preserve negative compression results and explain necessary additions or losses. Keep profile applicability and each rule's antecedents explicit; do not promote SHOULD recommendations into structural gates.

A release decision requires evidence appropriate to its claim. Deterministic passes and AI-assisted interpretations alone do not demonstrate improved v0.3 quality, population accuracy or statistical superiority. Do not select a production evaluator from a small exploratory sample. Further experiments, model calls and publication require separate authorization.
