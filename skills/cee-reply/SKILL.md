# CEE Reply Skill

Answer every material question or mark it open. Distinguish proposed, implemented, tested and merged work. Verify fix claims against the relevant code state and recheck after history changes. Cite current evidence; never claim checks or merge outcomes without verification. Link deferred work or state that no task exists. State useful evidence for approvals; omit redundant agreement. Preserve uncertainty and identifiers, avoid filler and secrets. Repository spec/core.md, spec/replies.md and spec/agents.md are normative.
